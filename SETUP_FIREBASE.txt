  CONFIGURACION MANUAL EN FIREBASE CONSOLE
=============================================================

1. IR A FIREBASE CONSOLE
   https://console.firebase.google.com/
   Seleccionar el proyecto: comdomoticaapp

2. HABILITAR AUTHENTICATION
   - Authentication -> Sign-in method
   - Habilitar "Email/Password"
   - Click "Save"

3. VERIFICAR USUARIO EXISTENTE
   - Authentication -> Users
   - Debe aparecer: polvoraul118@gmail.com
   - Copiar su UID (ej. PZjlZCFi69SNVT81G7Q909QpIII2)

4. CREAR ESTRUCTURA EN REALTIME DATABASE
   - Realtime Database -> Data
   - Debe verse asi (crear lo que falte con el boton "+"):

   {
     "devices": {
       "esp32_01": {
         "online": true,
         "led": 0
       }
     },
     "users": {
       "PZjlZCFi69SNVT81G7Q909QpIII2": {
         "email": "polvoraul118@gmail.com",
         "displayName": "Raul Polvo",
         "createdAt": 1780967871944,
         "deviceId": "esp32_01"
       }
     }
   }

   NOTA: El campo "deviceId" dentro del usuario es lo que la app
         lee para saber a que ESP32 esta vinculado.

5. ACTUALIZAR REGLAS DE SEGURIDAD
   - Realtime Database -> Rules
   - Pegar:

   {
     "rules": {
       "users": {
         "$uid": {
           ".read": "$uid === auth.uid",
           ".write": "$uid === auth.uid"
         }
       },
       "devices": {
         ".read": "auth.uid !== null",
         ".write": "auth.uid !== null"
       }
     }
   }

POSIBLES PROBLEMAS:

1. NO APARECE "WiFi CONECTADO"
   -> El ESP32 no se conecta a tu red WiFi
   -> Verifica que WIFI_SSID y WIFI_PASSWORD sean correctos
   -> Prueba con otro dispositivo en la misma red

2. APARECE "Esperando autenticacion..." INDEFINIDAMENTE
   -> Firebase Auth no valida el usuario
   -> Causas posibles:
      a) Email/Password NO esta habilitado en Firebase Console
         > Authentication > Sign-in method > Email/Password > Habilitar
      b) La contrasena en el codigo del ESP32 NO coincide con la
         contrasena real del usuario en Firebase Auth.
         > El ESP32 usa USER_PASSWORD = "2mN+nTfZBdUZr@S"
         > Para probar: abre la app Android e intenta iniciar sesion
           con email = "polvoraul118@gmail.com" y pass = "2mN+nTfZBdUZr@S"
         > Si NO funciona, cambia USER_PASSWORD en el codigo ESP32
           por la contrasena real que usaste al registrarte
         > O crea un usuario SEPARADO para el ESP32:
           Authentication > Add user > esp32@midominio.com / pass-fija
           y actualiza USER_EMAIL/USER_PASSWORD en el codigo ESP32
      c) El usuario no existe en Firebase Authentication
         > Revisar Authentication > Users

3. APARECE "ERROR escribiendo online"
   -> Las reglas de seguridad de RTDB bloquean la escritura
   -> Reglas de prueba temporales: { ".read": true, ".write": true }
   -> Despues de probar, volver a las reglas con auth

4. APARECE "ERROR leyendo led" con "PATH_NOT_EXIST"
   -> El campo "led" no existe en devices/esp32_01
   -> El ESP32 intentara crearlo automaticamente
   -> O crealo manualmente en Firebase Console

5. NO CAMBIA EL LED FISICO aunque el Serial diga "LED ENCENDIDO"
   -> El LED esta mal conectado
   -> GPiO 2 (D4) -> resistencia 220ohm -> LED -> GND
   -> Probar: conectar LED directo a 3.3V (sin ESP) para ver si funciona
   -> Probar: cambiar LED_PIN a otro GPIO (ej. 4, 5, 16, 18)
